# HW2.5

Цель работы — попробовать генеративные модели для расширения выборки и посмотреть, как синтетика влияет на качество классификатора.

Классический дисбаланс классов приводит к тому, что модель почти игнорирует редкие классы: точность по датасету может оставаться высокой, а полнота для minority-класса падает к нулю. Генеративные модели позволяют не только дублировать имеющиеся примеры, а синтезировать новые, более разнообразные объекты, тем самым увеличивая эффективный размер редкого класса и уменьшая смещение в сторону majority-классов.

ИМЕННО ЭТО И ПРОИСХОДИЛО В HW2

Stable Diffusion восстанавливает изображение из шума, а ControlNet добавляет дополнительное условие (контуры, поза, глубина и т.п.), что помогает контролировать структуру синтетических картинок и получать более осмысленные вариации класса. 

## Ход работы

В работе имитируется дисбаланс на CIFAR‑10: часть объектов выбранного класса “cat” удаляется, после чего модель сначала обучается только на урезанном датасете, а затем — на том же датасете, дополненном синтетическими изображениями этого класса. В качестве основных метрик используются:
- Accuracy — общая доля правильных ответов;
- Balanced Accuracy — усреднённая полнота по классам, более адекватная на несбалансированных данных.​

Ожидается, что добавление синтетики:
- заметно повысит recall и F1-score для редкого класса;
- увеличит balanced accuracy;
- может немного ухудшить качество по частым классам, но в целом модель станет более «честной» по отношению к minority-классу.


## Итоговые выводы

Генеративная аугментация с использованием Stable Diffusion + ControlNet оказывается рабочим инструментом для борьбы с дисбалансом: она даёт прирост по ключевым метрикам для редкого класса и позволяет гибко настраивать разнообразие примеров через промпты и типы контролирующих карт. При этом остаются ограничения по вычислительным ресурсам и риски distribution shift, поэтому в практических сценариях генерацию целесообразно комбинировать с классическими методами балансировки и регуляризации
